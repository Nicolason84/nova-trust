# France devient progressivement La Bête

**PROVEN pour la convergence du premier organe dette/taux**, au point de contrôle du 2 octobre 2026. La France entière n’est pas déclarée instrumentée.

La [surface publique](https://nicolason84.github.io/nova-trust/france-debt-rate-risk-live-2026-10-02.html) garde son URL. Elle projette désormais l’objet France existant → son système finance, avec budget associé → l’organe dette/taux/refinancement → la sortie exécutive existante. Les identités utilisent les schémas et pointeurs JSON déjà présents, sans créer une deuxième France, un deuxième modèle de dette, un runtime ou un bus.

Le Reality Pulse conserve cinq lectures immédiates : signal, changement, preuve, horizon et incertitude. Le dernier snapshot canonique est maintenant présent dans le HTML. JavaScript hydrate le même état, rejette les versions antérieures ou invalides et conserve la lecture connue si les feeds sont indisponibles. Le feed public et le JSON embarqué sont sémantiquement identiques et leur SHA-256 concorde.

La publication DGFiP de juillet était déjà inversée dans l’export Opendatasoft. La liste officielle du même PDF porte « 03 septembre 2026 ». Le réconciliateur de source produit `2026-09-03`, conserve le brut `2026-03-09`, exige une correspondance PDF/période et refuse une inversion générale des dates ISO. Les autres valeurs de dette, taux, courbes, stress, échéances et refinancement restent inchangées par cette mission.

La chaîne native est réelle : snapshot canonique → observation référencée → Megabus existant → MESSAGE_ROUTED → organe RUNTIME_OBSERVED dans `SUPRA_BODY_SCHEMA_V1` → impulsion traçable dans `SUPRA_NERVOUS_SYSTEM_V1`. L’adaptateur est une exécution unique attachée au watchdog existant. Il ne copie aucun chiffre, ne lance aucune capacité et déduplique les révisions matérielles. Sans nouvel événement, aucune nouvelle impulsion.

Le watchdog existant vérifie toutes les 300 secondes. Son seuil de 420 secondes empêchait le rythme attendu ; il est désormais de 290 secondes. Quatre exécutions autonomes réussies ont montré des écarts de 303, 303 et 304 secondes. Un nouveau heartbeat réussi est observé à 10:42:46 UTC alors que le snapshot matériel reste à 10:08:26 et l’observation de marché au 1er octobre. Les trois horloges sont séparées dans l’interface. Le déclenchement réel est `workflow_dispatch` depuis le Mac ; le cron GitHub natif n’est pas démontré. Mac éveillé, LaunchAgent enregistré et accès gh opérationnel restent nécessaires.

Les tests publics passent : desktop, portrait, paysage, JS OFF, feed/API indisponibles, mouvement réduit, trois exports et canvas 3D. Le débordement mobile découvert lors de ces tests est réparé. Le navigateur cloud sans WebGL garde un secours explicite. Les captures correspondent à un viewport mobile Chrome, sans prétendre certifier le Safari physique de Nicolas.

L’évolution reste gouvernée : ADN borné, candidate, tests, comparaison, publication uniquement après PASS, preuve et rollback. Le véritable vérificateur refuse une candidate qui muterait la vérité ; la restauration connue bonne a été testée en isolation. Aucun jugement politique, effet territorial automatique ou accès caméra/micro n’est promu.

Les reçus JSON, captures et [rapport de non-régression](FRANCE_BODY_NON_REGRESSION_REPORT.md) dans ce dossier documentent le périmètre exact. Le gel conserve les preuves de cette version ; il ne désactive pas la boucle vivante. Les organes budget, énergie, emploi et autres domaines restent les objets existants, prêts à être référencés par la même loi après leurs propres preuves.
