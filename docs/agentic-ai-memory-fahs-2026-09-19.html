Reference: 8,192 tokens × 4 sessions, 16-bit cache, no prefix sharing, with the same current weights and reserve. 1 GiB = 2³⁰ bytes. A logical capacity budget is not a guarantee of feasible multi-device placement.

The equation is the experience—not a black box.
k = 2 × L × Hkv × D × b
stored token equivalents = S × [p + N × (1 − p)]
KV (GiB) = k × stored token equivalents / 2³⁰
total (GiB) = W + R + KV

The factor 2 counts keys and values. L: layers; Hkv: KV heads; D: head dimension; b: bytes per element. S: tokens per session; N: resident sessions; p: identical prefix fraction. W and R are in GiB. The storage formula is our derivation from tensor shapes, with ideal prefix sharing. [2] [4] [5]

The calculation deliberately excludes sliding-window, latent and hybrid caches, eviction, replica weights, fragmentation, variable buffers and quantization metadata. A smaller nominal cache does not establish preserved quality or faster inference. Prefix sharing requires identical prefixes, a compatible engine and appropriate isolation. [3]

Each tower uses a common, automatically rescaled GiB-to-height mapping. Baseboards and label cards are schematic, not physical chip designs. No tokens-per-second, financial return or hardware performance is inferred from the geometry.

02 / FOLLOW THE DENOMINATOR

Two numbers.
Two different questions.

Abbas's post makes a useful infrastructure hypothesis. Reproducing it means asking which model, which workload and which memory metric are being compared. [0]

SUPPLIER CLAIM10–40×

Memory relative to standard inference.

Micron uses this range, but the retrieved article text does not disclose a comparable workload definition from which we can reproduce it. It remains a supplier claim, not a universal multiplier established by this lab. [1]

A DIFFERENT REFERENCE3–10×

Internal generation versus visible output.

Micron's wording compares internally generated tokens with those returned to the user. It is not directly an agent-versus-conventional-inference comparison. Finding the same figures does not establish which source Abbas used. [1]

Don't multiply the ranges automatically. If a memory estimate already includes additional generated tokens, applying a second token multiplier can double-count the same effect. A workload's cumulative token production is also not its simultaneously resident cache.

THE WORKING MEMORY OF DECODING

Reuse instead of recomputing.

A KV cache retains keys and values from processed tokens. For full attention, its size grows with retained context and resident sequences.

Total tokens generated across a mission are not the same as tokens resident in this cache at one moment.

04 / CAPACITY IS NOT BANDWIDTH

It fits.
Does it arrive in time?

Memory capacity and data movement impose different constraints. Offloading and separating inference stages change where work happens; they do not make transfers disappear. [3] [7] [8]

A transport calculation, not a response-time prediction.

The same byte count can produce different transport times. This small model separates volume, nominal bandwidth and the usable fraction. It excludes fixed latency, queues, serialization, repeated copies and overlap with computation.

No live link is measured. Changing the inputs recalculates the result; there is no pretend network traffic.

191.74 ms

Idealized transfer time, not time to first token or agent completion time.

Units and formula
t(ms) = volume_GiB × 2³⁰ × 1,000
/ (bandwidth_GB/s × 10⁹ × usable_fraction)

The percentage is converted to a fraction between 0 and 1. GB is decimal; GiB is binary. No advertised device bandwidth is automatically inserted.

Compatibility, controls and limits

Spatial browsers: WebXR availability depends on the browser, device and session mode. This page checks AR and VR independently, then handles permission denials and session failures. Browser support does not certify this build on a particular headset. [9]

Examples, not a device guarantee: WebKit documents immersive VR and natural input on visionOS; Google documents WebXR AR through ARCore on compatible Android Chrome devices. The actual capability check is authoritative for this page. [15] Glasses without a spatial browser or display do not gain AR merely by opening a link. [10] [11]

Inside XR: select a scenario card or Exit. The model starts fixed in front of you, not attached to your gaze. In AR, optional horizontal-surface hit testing enables placement; selecting a detected surface places the model. Without a supported surface result, it remains a floating spatial model. There is no persistent anchor, occlusion or room mesh. [14]

Snapshot: USDZ is an uncompressed, aligned package containing scene geometry and labels. It is a static representation of the parameters at export time. Package integrity can be checked without a headset; appearance and interactions still need physical-device testing. [13]

Comfort and privacy: use a clear space, stay still and stop if uncomfortable. No artificial locomotion or automatic camera rotation. No microphone access, camera recording, eye-tracking log or session data upload is implemented. The browser and OS manage any spatial permissions.

Validation boundary: screen rendering and calculations are testable here. Physical-headset tracking, passthrough, native Quick Look presentation and comfort are not certified by a desktop test. An unsupported mode stays unavailable; the full numerical lab remains usable.
06 / FROM HYPOTHESIS TO MEASUREMENT

Find the bottleneck.
Then test the intervention.

01

Hold the task constant.

Specify model, quality threshold and latency target. Distinguish completed tasks, model requests and concurrently resident sessions.

02

Measure the critical path.

Observe resident KV, allocated memory, achieved throughput, first-token delay, inter-token gaps and time spent in tools.

03

Change one lever.

Test context, prefix sharing, cache format and offload separately. Recheck quality. Compare cost per correctly completed task, not just raw tokens.

This is a proposed measurement protocol. GQA, paging and context selection can change resource use; none alone establishes who captures the economic value. No security is valued or recommended here. [4] [5] [6]
