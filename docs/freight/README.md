# ojO × FREIGHT 1.6 — NOVA ERA

## [Ouvrir l’application sans compte](https://ojo-freight-nova-era.netlify.app/)

**[Page de présentation partageable](https://nicolason84.github.io/nova-trust/freight/)**

La version 1.6.0 conserve le site et les espaces locaux existants. Le dialogue métier
garde le contexte, demande les données manquantes et prépare un devis dont
l’enregistrement reste explicite. Comparaisons, suivi et brouillons complètent
le parcours ; les montants ou disponibilités inconnus restent à confirmer.

**[Gazole & trésorerie](https://ojo-freight-nova-era.netlify.app/#gazole)** réutilise
le moteur patrimonial OJO Gazole 1.0. Les paramètres initiaux sont fictifs et leurs
conventions restent visibles avant la comparaison sur 180 jours. Le résultat
distingue activité, trésorerie et besoin non couvert ; l’export porte uniquement
sur cette simulation. Il ne détermine pas un régime fiscal ou un financement.

Pas de compte ChatGPT, GitHub ou Netlify demandé aux utilisateurs. Le lien partage
l’outil, jamais les données du navigateur de l’expéditeur. Les données ne sont pas
synchronisées entre collègues ou appareils. Exportez régulièrement une sauvegarde.

La surface publique ne comprend pas de conversation IA générative générale ou de
lecture des boîtes e-mail, SMS et WhatsApp. Les messages restent des brouillons
à relire et à ouvrir explicitement dans la messagerie choisie, sans envoi automatique.
Les modules à développer sont distincts des outils utilisables.

Cette page est une présentation statique. L’application est hébergée séparément
sur le site Netlify existant du compte NOVA ERA. Pages reste configuré sur
main, dossier /docs, avec son circuit legacy existant ; aucun workflow n’est ajouté.
Le code de développement et les données privées restent dans leurs dépôts privés.
