# ojO × FREIGHT — NOVA ERA

## [Ouvrir l’application sans compte](https://ojo-freight-nova-era.netlify.app/)

**[Page de présentation partageable sur GitHub Pages](https://nicolason84.github.io/nova-trust/freight/)**

Version 1.5.0 : chat métier local, calculs de prix et marge, consultations,
devis, suivi commercial, catalogue de modules et brouillons de messages.
Pas de compte ChatGPT, GitHub ou Netlify demandé aux utilisateurs.

Le lien partage l’outil, jamais les données du navigateur de l’expéditeur.
Un nouveau navigateur ouvre un espace vide. Les données ne sont pas synchronisées
entre collègues ou appareils. Exportez régulièrement une sauvegarde.

Cette version ne comprend pas de conversation IA générative ou de lecture des
boîtes mail, SMS et WhatsApp. Les messages sont des brouillons à relire et à envoyer
manuellement dans la messagerie de l’utilisateur. Les modules à développer sont
explicitement distingués des trois familles d’outils disponibles.

Ajout à l’écran d’accueil : instructions dans Mon application.
Le code de développement et les données privées restent dans les dépôts privés.
Cette page présente le projet ; l’application est hébergée chez Netlify sur le
compte NOVA ERA. Aucun logiciel commercial n’est servi directement par Pages.
