Source drift detected — and exposed

Some current Global Property Guide pages return different 10-year nominal values for the same market across regional and country-level snapshots. This prototype does not silently pick one. It stores the observed range and raises a conflict flag.

This is a data-lineage issue, not a claim that either snapshot is “wrong”. The next co-build step is to pin each series to exact source, geography, reference quarter and revision.

02 · discovery preserved

The market field

Click a market. The horizontal axis is annualized 5-year real house-price change; the vertical axis is current gross rental yield. Bubble halo intensity reflects the current mortgage rate.

The chart is a screening field, not an investable ranking. Gross yield is based on listing-derived median prices and rents; 5-year price change is historical; mortgage rates are current snapshots. Geographic coverage can differ by series.
